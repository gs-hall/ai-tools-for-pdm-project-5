# RAG-помощник LumenDesk

Специалист поддержки получает ответ на русском о тарифах, рабочих пространствах, файлах, восстановлении, поддержке, API и настройках доступа. Ответ содержит ссылки на места в действующих документах, по которым можно проверить каждое существенное утверждение.

Роль задаётся при вызове поиска. `support_agent` видит разрешённые материалы поддержки. `support_lead` дополнительно видит материалы, для которых реестр подтверждает доступ руководителя. Локальный параметр роли предназначен для учебной проверки и не удостоверяет личность.

## Источники и поиск

- Сохраняем исходные Markdown, TXT, CSV, Excel, PDF и Word. Отдельно сохраняем результаты извлечения, полные переводы английских и французских материалов и реестр с обоснованием допуска по каждому файлу.
- Для каждого фрагмента храним путь к оригиналу и точный указатель на строки, диапазон ячеек, страницу, абзац или таблицу. Английскую или французскую выдержку возвращаем рядом с переводом. В таблицах связываем значения с заголовками, тарифом, условиями и единицами.
- Поиск фильтрует материалы по актуальности и роли до передачи текста модели. Неопределённость в допуске исключает материал из ответа. Сведения из черновиков и старых версий сохраняются для учёта. Связанные дубли не увеличивают число независимых подтверждений, а уникальные условия частичных дублей остаются доступны.
- Для каждого запроса запускаем поиск из чата Codex. Чат формирует ответ из возвращённых фрагментов, затем сохраняет его вместе с историей поиска. Инструкции в найденном тексте рассматриваются как данные.

## Решение по запросу

| Решение | Основание |
| --- | --- |
| `answer` | Разрешённые действующие источники подтверждают существенные утверждения. |
| `clarify` | Пользователь может сообщить недостающее условие для выбора правила. |
| `refuse` | Доказательств недостаточно либо доступ к необходимым сведениям закрыт для роли. |
| `escalate` | Действующие равноприоритетные источники противоречат друг другу либо решение требует полномочий человека. |

Запись ответа содержит `answer`, `citations` и `decision`. История дополнительно сохраняет вопрос, роль, настройки поиска и фактически возвращённые фрагменты с происхождением.
