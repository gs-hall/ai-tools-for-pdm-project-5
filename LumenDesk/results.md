## Воспроизведение и границы применения

На macOS команда из README воспроизвела извлечение в новой папке с отдельным Python 3.12 окружением, собрала индекс и выполнила [вопрос 1 с сохранением ответа](history/20261124T161546-69e7e6e806d7.json). Для сборки использован уже загруженный снимок BGE-M3.

Помощник применим к описанным проверками документированным правилам поддержки. Для недостающего тарифа он уточняет условие. При закрытом источнике или недостатке доказательств он отказывает. Конфликт двух действующих ставок передаётся Finance и Support Operations. По другим темам, особенно при переводе договорных условий, перед ответом нужно сверить цитату с оригиналом. Локальная роль не удостоверяет личность и не защищает сами файлы в файловой системе.
